# Excel PivotTable Basics

## Project Overview

This project demonstrates basic sales analysis using Excel PivotTables with Superstore data.

The analysis focuses on sales performance across different categories, regions, and months.

## Objectives

- Create PivotTables for quick sales summaries.
- Analyze sales by category.
- Analyze sales by region.
- Analyze monthly sales trends.
- Identify useful business insights from the summaries.

## PivotTables Created

### 1. Sales by Category
Summarizes total sales for each product category.

### 2. Sales by Region
Summarizes total sales across different regions.

### 3. Sales by Month
Shows sales performance month by month to identify trends.

## Tools Used

- Microsoft Excel
- PivotTables
- Superstore Dataset

## Key Insights

- Category-wise sales can be compared using PivotTables.
- Regional performance can be identified quickly.
- Monthly analysis helps understand sales trends.
- PivotTables make large datasets easier to summarize and analyze.

## Project Deliverables

- Excel workbook containing the analysis
- 3 PivotTables
- Short business insights
- Project documentation
